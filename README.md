# مدى (Mada) — الباحث عن أقوى إشارة

تطبيق أندرويد يساعدك تلقى أقوى إشارة جوال حولك (بدون خدمات Google، يشتغل على هواوي).

- مقياس مباشر للإشارة (dBm، RSRP/RSRQ/SINR) ونوع الشبكة والمشغّل (زين، أوريدو، stc الكويت).
- رسم بياني مباشر، ووضع «الباحث» دافي/بارد بالصفير والاهتزاز.
- خريطة حرارية للإشارة على OpenStreetMap تنحفظ للاستخدام بدون نت.
- معلومات البرج المتصل فيه، واتجاه الإشارة الأقوى حسب قراءاتك.
- اختصارات: وضع الطيران، إعدادات الشبكة، نوع الشبكة المفضّل.

> بصراحة: ما فيه تطبيق يقدر يقوّي الإشارة. «مدى» يساعدك تلقى المكان الأقوى فقط.
